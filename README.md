# 《俗世奇人》数字交互书籍设计库

这是一个面向数字阅读产品的设计底座，服务于“沉浸式阅读 + 情感化交互 + Vibe Coding 快速原型”。主阅读区已收录用户提供的《俗世奇人》Word 原文；设计词库仍不替代编辑、版权审核或历史考据。

## 设计判断

把《俗世奇人》做成“市井说书台”，而不是“奇人闯关游戏”。

- 内容单位不是宏大章节，而是“一页一人、一物见性”的短篇场景。
- 读者身份不是主角，而是茶馆里的看客、街口的路人、手艺人的临时学徒。
- 交互重点是“看、听、停、留印”，不靠积分解锁剧情。
- 每篇保留短、快、脆的说书节奏，在高潮与翻底之后留一段无声回响。
- AI 承担说书人、物件讲解者和情绪映射器，不能续写、改判或替代原文。
- 视觉世界落在煤烟、旧纸、砖灰、靛蓝与朱印之间，避免灯笼、祥云、龙纹和仿古卷轴拼贴。

## 首选体验结构

`入卫 → 翻册 → 围观 → 翻底 → 留印 → 回看`

1. **入卫**：以街声、门帘、灯影和地名建立进入感。
2. **翻册**：以“奇人签”而非普通书封索引人物，可按“能耐、气性、场面”找故事。
3. **围观**：正文阅读保持在视觉中心，环境和手艺信息藏在边缘，不打断句子。
4. **翻底**：关键转折前主动收声、收色、留白，让文本自己完成最后一击。
5. **留印**：读者选择“服气、哏儿、心酸、膈应、唏嘘、暖、醒”等情绪印，形成私人《观人录》。
6. **回看**：人物关系、器物和情绪印在“市井回声”中逐渐积累。

## 狗不理序章

《狗不理》使用两段连续的图文序章：

1. “巷口”展示天津老街包子铺插画和两段文字，读完后进入“铺子”。
2. “铺子”先展示运河边老高与狗子的插画和两段身世文字，读完后才进入正式
   铺面；正式铺面的底图使用忙碌清晨插画。

桌面端图片和阅读区左右并排，手机端上下排列；每段文字区域独立滚动并显示
阅读进度。相关图片位于：

## 原文数据与校验

原文数据取自用户提供的 `俗世奇人.docx`，文件 SHA-256 为
`8ff3050cc23b0fdb3f8fa26caeb5edf9311ce8635d0b4a767072b9779a01d519`。
当前收录黑头 24 段、泥人张 12 段、狗不理 14 段、四十八样 34 段，共
84 个自然段。网页只读取这一份数据；人物场景保持独立，和原文段落通过
`sceneIds` 关联。

修改原文后运行以下校验，确认段落顺序、内容和来源指纹仍一致：

```powershell
python scripts/verify_original_text_source.py C:\path\to\俗世奇人.docx web\data\original-text.js
```

## 库规模与校验

- 书籍词库：73 条，12 个字段，覆盖全书母题、空间、人物、物件、行当、感官、方言气质和叙事节拍。
- 视觉特征库：63 条，11 个字段，覆盖色彩、材质、字体、版式、图像、动效、声音和组件。
- 篇目交互图谱：12 个经典篇目样本，记录主题、标志物、交互、情绪曲线和翻底处理。
- 数据检查：CSV 列数一致、ID 无重复，两份 JSON 均可解析。
- 对比度检查：墨色正文／旧纸 13.22:1，墨色正文／宣白 15.39:1，宣白字／靛蓝 7.61:1，朱砂／宣白 5.30:1。

字库、图片和声音文件尚未加入。当前阶段提供的是可驱动后续制作的规则与来源要求，不把概念素材冒充已完成授权资产。

## 当前假设

- 项目使用《俗世奇人》的经典合集或包含《刷子李》《泥人张》《苏七块》等篇目的版本；未指定具体出版社和卷册。
- 词库中的“篇目锚点”用于设计索引，不声称覆盖不同版本的完整篇目表。
- 正式上线前需确定文本、图像、字体、音效和改编授权；AI 生成内容须经过编辑校订。

## MVP 建议

先做《刷子李》一条完整纵向切片：完成“黑与白”人物的入场、刷浆动作、疑点放大、翻底留白、情绪留印五段。它视觉反差清楚、情节短、交互不需要高成本 3D，最能验证产品气质。
