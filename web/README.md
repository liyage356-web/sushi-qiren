# 《俗世奇人·奇境入巷》网页原型

## 如何运行

直接双击 `index.html`，用浏览器打开即可。当前版本不需要安装 Node.js、不需要服务器，也不需要账号或数据库。

从首页进入天津老街后，点击场景中的“黑头”，或点击手机底部的人物入口，即可进入《黑头》阅读体验。

点击老街中的“泥人张”，在人物卡片底部选择“进入故事”，即可打开《泥人张》七幕交互体验。

点击老街中的“狗不理”，即可直接进入集成在主页面中的《狗不理》五幕交互体验。

点击老街中的“俞六（四十八样）”，即可跳过人物卡片，直接进入《四十八样》
七章交互阅读的第一章“默默无闻的卖糖人”。

## 当前功能

- 首页、天津老街和《黑头》篇目阅读均可正常进入与返回。
- 首页点击“入巷”后，闭合奇人档案袋从画面中心弹跳出现；随后可点击系绳开封、
  横置档案并从袋口向右抽出人物内页。首页与背景保持不变，不再播放翻书动画。
- 《黑头》包含“门前、院落、尾声、读后笺”四个阶段，可通过顶部阶段导航直达或返回。
- 《黑头》交互体验采用全屏视口布局：街道与鱼头场景铺满四边，工具栏和章节导航
  悬浮在场景之上；院落、原文与读后笺在视口内部独立滚动。
- 门前的鱼头支持轻点、向右拖动和键盘操作，会改变黑头靠近、停顿和回应的画面状态。
- 院落包含“跟随、接纳、守护、离开”四个可自由切换的场景状态。
- 原文阅读区与互动分离；“直接读原文”始终可用，不要求完成鱼头互动。
- 动画可关闭；声音默认关闭，可在右上角开启或关闭。
- 读后笺支持多选关键词、自由书写，并使用浏览器本地存储保存。
- 桌面端与手机端均使用原生 HTML、CSS 和 JavaScript，没有引入框架。
- 《泥人张》包含天庆馆、人物观察、三步捏泥、泥像亮相、估衣街、结局和读后笺七幕。
- 《泥人张》的原文摘引会标注来源和“原文/场景转述”状态，不把设计稿转述冒充原著。
- 《狗不理》已形成“巷口、铺子、制作、经营、名字、远播、读后笺”七页完整阅读闭环，
  支持两段图文序章、四工序制作、经营观察、名字反转、名声传播、本地读后笺和原文入口。
- 《狗不理》的街声默认关闭，点击后由浏览器生成轻量环境声，可随时开关。
- 《四十八样》七章已经完成天津老街、十二样药糖图鉴、五步“二龙戏珠”挑担组装、
  八步走八字与完整表演、“绝活被仿后的三项再创新”、天津六句词方言语音、
  原著结尾和本地读后感悟；完整八天送糖图鉴与挑担装配音效仍为待接入项。
- 首页“入巷”后会播放奇人档案入场、解绳开封、横置和内页抽出的完整交互动画。

## 奇人档案交互动画

打开 `index.html`，点击首页“入巷”按钮测试完整流程：

1. 档案弹出约 `0–0.8s`：点击“入巷”后，闭合档案从画面中心由 `0.65` 放大至
   `1.04`，再轻微回弹并稳定居中；原首页与背景始终保留。
2. 档案落定后进入 `CLOSED` 状态，提示“档案落定 · 点击系绳启封”，系绳按钮获得焦点。
3. 解绳开封 `0.8–2.0s`：仅点击系绳后，棉线先抖动松脱并移出，封口折盖随后
   翻起；打开后保留一条独立垂线，最终停在 Figma 中间态等待下一操作。
4. 旋转横置 `2.0–2.9s`：点击已打开的档案任意位置，纸袋以自身中心为轴顺时针
   旋转 90 度，并移动到左侧最终位置；松散棉线在旋转开始时淡出。
5. 纸张抽出并放置 `2.9–5.0s`：旋转完成后，人物内页从袋身前景右侧的袋口连续向右滑出；
   纸张不继承纸袋旋转，正文始终保持正向。后层衬页在纸张之后，完整袋身前景始终压在
   纸张前方；约 `1.55s` 完全离开袋口后，再用 `0.55s` 抬到独立阅读层、平移到画面中心
   并放大。抽出过程与最终阅读放置是两个连续但独立的动画阶段。
6. 抽纸完成后，五张内页按“卷宗总览 → 狗不理 → 黑头 → 泥人张 → 俞六”
   的顺序叠放；点击当前纸页依次翻阅，第五页再次点击后直接进入天津老街。

桌面端闭合档案按视口尺寸计算大小，约为画面宽度的 `34%`、高度的 `84%`；
开封时会轻微缩小并下移，为向上翻起的折盖留出空间。手机端约为视口宽度的
`86%`，旋转后自动切换为上下错层布局。桌面端抽纸完成后，纸页左缘停在横向
袋口右侧；完全离开袋口后，纸页居中放大并以高度、视口宽度和 `1040px` 上限约束，
五页纸叠完整落在视口内。横置袋身与人物内页
使用同一响应式宽度，纸张的起止位置也由这两者的实际边界计算。

抽出过程中纸张运动层固定为 `z-index: 10`，袋身前景为 `z-index: 20`。只有纸张
完全离开袋口、抽出阶段结束后，阅读层才切换为 `z-index: 30` 并开始居中放大。
纸张自身不使用随元素移动的 `clip-path`，袋内遮挡完全由实际袋身前景完成；
袋口接触阴影锚定在袋身前景右缘，并随抽出进度减弱。

调试抽纸阶段时可追加 `?paperProgress=0.25`、`0.5` 或 `0.75`；只有显式提供该参数时
时间线才会暂停在指定进度，正常访问不会停住动画。

四段动画分别由前一阶段完成和对应点击事件解锁。刷新页面会重置为首页，档案左上角的
“重新观看”可以重复测试动画。动画状态由
`HOME → ENTERING → CLOSED → UNTYING → OPEN → ROTATING → PAPER_SLIDING → COMPLETE`
单向控制；每一段动画完成后才会更新状态，动画期间重复点击不会再次触发。

```text

```

## 《泥人张》的运行与测试

直接打开 `index.html#street`，点击“泥人张”人物热点，再点击人物卡片底部的“进入故事”；
也可以直接打开 `mi-ren-zhang.html`。

建议按以下顺序测试：

1. 点击天庆馆中的酒杯、门口、吃客和泥人张，确认观察面板会更新。
2. 在“识人”中切换泥人张与海张五，确认人物说明随之变化。
3. 在“捏泥”中点击泥团，再点击大头、眼睛和嘴巴，确认进入第三步并显示完成态。
4. 在“亮相”中点击头部、眼睛和整体，再点击“看看众人的反应”。
5. 在估衣街点击各个摊位，确认纸条是最后一个摊位。
6. 打开“原文阅读”，检查每一段是否标明“摘引或场景转述”。
7. 在手机宽度下检查章节导航、泥塑按钮、摊位横滑和读后笺。

## 《泥人张》文件说明

- `mi-ren-zhang.html`：七幕页面、按钮、可访问标签和原文摘引弹窗的结构。
- `mi-ren-zhang.css`：宣纸、雨景、泥塑、人物卡、估衣街和手机端样式。
- `mi-ren-zhang.js`：章节切换、观察、泥塑步骤、摊位和本地保存等交互逻辑。
- `mi-ren-zhang-story.js`：故事文案、观察内容、泥塑提示、摘引来源和读后关键词。

初学修改时优先编辑 `mi-ren-zhang-story.js`。例如把新的泥塑步骤图放进
`images/characters/` 后，可在 `mi-ren-zhang.html` 中把对应的 CSS 泥团占位元素换成
`<img>`，再在 `mi-ren-zhang.js` 的 `setCraftStep()` 中切换图片地址。

当前天庆馆与海张五使用 CSS 场景占位，泥像使用现有泥人张插画中的局部裁切。
替换正式插画时，请保留 `.asset-note` 或同步更新图片来源说明。

《泥人张》读后笺保存在当前浏览器的以下键中：

```text
reading-note-nirenzhang
```

旧键 `sushi-qiren-ni-ren-zhang-reflection-v1` 和
`reading-note-ni-ren-zhang` 会在首次读取时兼容迁移。

### 连续滚动阅读

“巷口”“入铺”和“正式铺面”共用 `#dogPages` 一个真实滚动容器。桌面端正文保持左侧定位，
宽度约为视口的 `33%`；背景由两层固定插画组成，只有进入场景过渡区时才按滚动进度交叉淡化。

阅读进度按正文末段的实际位置计算，不监听滚轮次数。当前段未读完时不会切换，读完并继续向下
才进入下一场；反向滚动会同步恢复上一张背景和“巷口／铺子”导航状态。手机端扩展为近全宽正文，
平板端继续保持约三分之一宽度。`prefers-reduced-motion` 开启时，交叉淡化改为跨过中点后直接切换。

建议这样测试：

1. 从老街进入“巷口”，确认首先显示街景、左侧约三分之一宽的标题和正文，且页面停在顶部。
2. 滚动到正文中点，确认仍在“巷口”；读到最后一段并继续向下，确认“铺子”高亮且两张背景淡化切换。
3. 向上滚动确认返回上一场；点击“巷口／铺子”确认平滑定位到对应场景开头。
4. 在 `1024px` 平板和 `390px` 手机检查正文宽度、触摸滚动、工具栏和横向章节导航，确认无横向溢出。
5. 打开减少动态效果后重复场景过渡，确认不再播放连续淡化，但阅读与导航状态保持一致。
6. 点击“跳过互动”和“阅读原文”，确认任一场景都能打开完整原文，并按 `Esc` 或关闭按钮退出。
7. 进入“制作”完成任一互动后返回故事，确认制作进度、章节状态和重新体验仍然正常。

## 录入原著原文

目前没有把故事简介或改写文字冒充原著。末尾阅读区会明确显示“原文尚未录入”。

打开 `hei-tou-story.js`，找到 `canonicalText: []`。录入已授权并核对的原著段落，例如：

```js
canonicalText: [
  {
    heading: "第一部分标题（如果原文有此标题）",
    paragraphs: [
      "这里粘贴核对后的原文第一段。",
      "这里粘贴核对后的原文第二段。",
    ],
  },
],
```

同时可以把 `source.statusLabel` 改为“原文已核对录入”，并在 `source.edition` 中记录出版社、版本等信息。

不要在这里添加摘要、续写、解释或自己加工过的小说段落。页面会按数组顺序原样输出文字。

## 替换图片

当前三处图像情况不同：

- 人物：使用已有的 `images/characters/hei-tou-cutout.png`。
- 商铺门前：使用 HTML/CSS 场景示意，并在画面左上角标记“场景图占位”。
- 商家院落：使用 HTML/CSS 场景示意，并在画面左上角标记“场景图占位”。

拿到正式图片后，可把门前或院落画布中的 CSS 示意替换为普通图片，例如：

```html
<img src="images/hei-tou-shopfront.jpg" alt="北大管商铺门前场景" />
```

图片文件应放在 `web/images/` 下，或建立单独的篇目目录。请在替换后同步调整人物与鱼头的位置，并保留“素材来源”说明。

## 读后笺保存在哪里

读后笺保存在当前浏览器的 `localStorage` 中，键名是：

```text
reading-note-heitou
```

旧键 `sushi-qiren-hei-tou-reflection-v1` 会在首次读取时兼容迁移。
它不会上传到网络。清除浏览器站点数据、换浏览器或换设备后，已保存内容不会自动迁移。
