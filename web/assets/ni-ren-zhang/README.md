# 《泥人张》素材说明

- `tianqingguan-rainy.webp`：用户提供的《雨中茶馆的闲适时光》插画，
  用于集成版第一幕天庆馆场景。原图仅做 WebP 压缩，构图与内容未改动。
- `rainy-tianqingguan-teahouse-crowd.png`：用户提供的《雨日天庆馆茶楼群像》
  插画，当前用于第一幕天庆馆全屏背景；项目副本与源文件逐字节一致。
- `sea-zhang-wu-enters-tianqingguan.png`：用户提供的《张五爷入天庆馆》
  插画，用于穿过天庆馆远端门框后进入的第二幕“识人”场景。
- `sea-zhang-wu-insitu-overlay.png`：从上述场景中分离出的海张五交互层。
  像素、尺寸和位置与背景人物完全一致；外部透明区域不遮挡其他人物或建筑。
- 泥人张人物图复用 `../../images/characters/ni-ren-zhang-cutout.png`。
- 海张五泥像复用 `../../images/characters/hai-zhang-wu-clay.png`。
- 海张五真人交互层由场景原像素分离生成，悬停高亮和点击观察共用该区域。
- 泥团、头像和完成泥像使用 CSS 占位，第二、三阶段可直接替换为图片序列。

所有热点、按钮和故事文字均为网页原生元素，没有烘焙在插画中。
