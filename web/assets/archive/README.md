## 动画分层

横向状态按真实夹层顺序组织：

| 层级 | DOM | 作用 |
| --- | --- | --- |
| `z-index: 4` | `archiveBagBack` | 袋身后层、掀开封盖和内衬，位于纸张之后 |
| `z-index: 10` | `archivePaperWindow` | 五页纸张及其袋口接触阴影 |
| `z-index: 20` | `archiveFolderShell` | 完整袋身前景、前沿、纸边高光与操作层 |

1. `archive-bag-body.png` 是当前可用的完整不透明袋身前景，精确覆盖纸张在袋内的区域。
2. 纸张不再使用 `clip-path` 伪造袋内裁切；未抽出的部分由真实袋身 PNG 像素遮挡，
   已抽出的部分在袋外完整显示。
3. 打开态封盖与内衬放在 `archiveBagBack` 内，因此纸张从它们前方、袋身前景后方经过。
4. 横置完成后，`archiveHorizontalAsset` 以完整原图覆盖旧分层；旧
   `archiveBagBack` 与 `archiveFolder` 隐藏，避免重复纸扣、边缘和纹理。
5. 抽纸期间只以完整素材内袋身外缘作为袋口位置，并用同一范围限制纸张顶部、
   底部和左侧可见区域。纸张位于完整素材后方，离开袋口后才继续显示。
6. `archiveContactShadow` 固定在袋口，不随纸张平移，并随抽出进度减弱至消失。
7. 手机竖屏会将完整素材等比缩入屏幕安全宽度，保证右侧绳子不被裁切；桌面端以
   当前前封面宽高和中心作为替换基准。
8. 每次点击揭开当前纸页并显示下一张；第五页再次点击后进入天津老街。

五页内页是五个独立 `<button>` 图层，不合并成单一图片。纸张从前到后的静态
堆叠参数为：

| 可见顺序 | `translateX` | `translateY` | `rotate` | `z-index` |
| --- | ---: | ---: | ---: | ---: |
| 1（当前页） | `0px` | `0px` | `0deg` | `5` |
| 2 | `-9px` | `-7px` | `-2deg` | `4` |
| 3 | `7px` | `-5px` | `1.5deg` | `3` |
| 4 | `-13px` | `4px` | `-3deg` | `2` |
| 5 | `4px` | `7px` | `2deg` | `1` |

翻页后，剩余纸张会按同一组无序方向参数重新分配位置，所以不会沿右下角形成
机械阶梯。动画结束后纸张、容器和图片均回到 `scale: 1`，容器滤镜为 `none`、
`will-change: auto`，避免静止阅读时继续发生重采样。

各阶段由页面提示的点击操作推进：

| 时间段 | 动画 | 完成状态 |
| --- | --- | --- |
| 0–0.8s | 档案弹入并回弹 | `CLOSED` |
| 0–0.2s | 点击下扣时的按压与回弹、绳线轻微绷紧 | `UNTYING` |
| 0.2–1.7s | 第一圈沿上下纸扣逆时针退绕并清零 | `UNTYING` |
| 1.7–3.2s | 第二圈连续逆时针退绕并清零 | `UNTYING` |
| 3.2–3.7s | 绳尾自然松脱垂落 | `UNTYING` |
| 3.7–约 4.5s | 自动衔接到原有折盖展开与回弹 | `OPEN` |
| 进入 `OPEN` 后 0.9s | 档案袋顺时针旋转 90° | `ROTATING` 完成 |
| 横置后 2.1s | 内页向右抽出 1.55s，再居中放大 0.55s | `COMPLETE` |

Figma 横置设计中的 `10:57 文献衬页`、`10:58 人物档案内页`、`10:59 袋口开口`
与 `10:60 牛皮纸袋本体` 共同确定了纸张位于袋身之后的空间关系；`10:93 袋口前沿`
和 `10:94 袋口纸边高光` 在网页中由完整袋身前景、`archiveMouthShadow` 与
`archiveContactShadow` 共同还原。Figma 当前账号仍无该文件编辑权限，无法额外导出
独立前后片；现有修复复用已确认的完整袋身前景作为遮挡层，没有绘制纯色矩形冒充袋身。

纸页完全离开袋口前始终保持 `z-index: 10`，由 `z-index: 20` 的袋身前景遮挡。
抽出结束后才进入 `archive-paper-reading`：纸张抬到 `z-index: 30`，保持横向正向，
平移到视口中心并放大到适合阅读的尺寸。

调试时可追加 `?paperProgress=0.25`、`0.5` 或 `0.75` 检查抽纸中间帧。

解绳动画按上下纸扣圆心和半径逐帧重建 SVG 路径，不使用整张图片旋转或透明度
切换。两条绳路各负责整整一圈绕扣量，第一圈归零后第二圈从同一时间边界继续；
两圈松解和绳尾垂落共 `3.7s`，之后自动衔接到原有折盖展开。调试时可追加
`?cordProgress=0.25`、`0.5` 或 `0.75` 检查中间帧。主要参数位于
`archive-interaction.js` 的 `CORD_UNTIE_DURATION`、`TIE_PIVOTS`、
`TIE_ROPE_CONFIGS` 与 `TIE_SLACK_START`。

人物卡文字、标签、插画、印章和翻页顺序依据 `ULxh0kGdQIdNBH3VXPhFnr` 中
`人物档案内页1` 至 `人物档案内页5` 实现。人物插画复用项目中已确认的透明 PNG。

## 横向袋口抽出收纳

档案横置后，纸张不再沿用旋转前的硬编码起点。运行时先读取档案袋前景旋转后的
实际包围盒，再测量五张纸连同各自旋转、错位后的整体可见边界：

- 纸张起点以五张纸的联合边界计算，最后一张纸的右侧停在袋口内约
  `2–3px`，不会在动画开始前露出。
- 纸张纵向中心与横置档案袋中心对齐；抽出过程中只保留约 `±1.2px` 的自然起伏，
  不再从画布上方移动到画布中心。
- `archivePaperWindow` 在抽出阶段使用动态 `clip-path:
  inset(0 0 0 <袋口位置>)`，只显示袋口右侧已经抽出的部分。袋内区域由
  `z-index: 20` 的完整档案袋前景遮挡，纸张层保持 `z-index: 10`。
- 纸张完全离开袋口后才切到阅读层 `z-index: 30`，移除裁切并放大到原有阅读尺寸。
- 抽出阶段暂关闭单页投影，避免纸张仍在袋内时投影越过袋口；纸张开始露出后再
  由整组纸张的合成投影补充层次。

调试时可继续使用 `?paperProgress=0`、`0.25`、`0.5`、`0.75` 检查收纳、四分之一、
中段和即将完成状态；`scripts/qa_archive_extraction.js` 会用像素差验证袋口左侧
没有纸张提前出现。
