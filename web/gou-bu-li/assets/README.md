# 《狗不理》素材说明

- `bao-shop-busy.webp`：用户提供的《包子铺里的温暖忙碌时光》插画，用于第一幕
  天津老街与包子铺内景。原图已压缩为 WebP，构图与内容不改动。
- `gou-bu-li.png`：复用项目现有人物插画，用于狗子人物展示。
- `tianjin-street.jpg`：复用项目现有天津老街图，用于街景背景。
- `paper-fibers.png`：复用项目现有宣纸纹理。

包馅、四步制作、蒸笼、钱箱和招牌目前使用 HTML/CSS 占位绘制，避免假装已有正式插画。
替换时请保持图片文件名不变，或同步修改 `index.html` 中的图片路径与 `alt` 文本。

当前第一幕的招牌、蒸笼、狗子和顾客热点均为透明 HTML 按钮，文字不会被烘焙进插画。
