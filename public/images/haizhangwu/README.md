# 海张五人物视角素材

完整八视角位于 `rotation/`，文件名、角度和来源如下：

- `view-000.png`：0° 正面，来自《传统中式水墨扇舞者》
- `view-045.png`：45° 右前侧，来自《得意洋洋的清代官绅像》
- `view-090.png`：90° 右侧，沿用原项目 `right-side.png`
- `view-135.png`：135° 右后侧，来自《紫袍商贾持扇回望》
- `view-180.png`：180° 背面，来自《传统服饰中的背影老人》
- `view-225.png`：225° 左后侧，来自《回眸持扇的古装长者》
- `view-270.png`：270° 左侧，来自《清代风雅持扇人物》
- `view-315.png`：315° 左前侧，来自《海张五侧身持扇水墨像》

所有图片均为独立透明 PNG，没有镜像、复制或用相似侧背影冒充缺失角度。
`水墨画风的得意清朝富商.png` 的朝向与已采用的 135° 视角过近，因此保留为候选图，
未加入旋转序列。

根目录下的 `front.png`、`front-walk.png`、`left-side.png`、`right-side.png`
与 `back.png` 继续作为八帧未全部通过加载检查时的有限视角回退素材。

新增或替换角度素材时，应保持 `1024 × 1536` 左右的透明画布、统一的人物高度和
脚底位置，并同步修改 `web/haizhangwu-view-config.js`。观察组件会先预加载全部
八帧；只有八帧都成功加载时才开放 360° 循环。

## 高清放大素材

当前正面源图只有 `1024 × 1536`。桌面 DPR 1 下 3 倍缩放仍处于原生像素范围内，
但高 DPI 屏幕和 4 倍缩放会需要更大的源图。若要覆盖移动端 DPR 2 的 4 倍查看，
建议提供同画风、同构图的透明 PNG：`3072 × 4608`，仍保持 2:3 比例。

将文件放在 `rotation/`，例如 `view-000-hd.png`，然后在
`web/haizhangwu-view-config.js` 的 `configuredHighResSources.front` 中填入：

```js
front: "/public/images/haizhangwu/rotation/view-000-hd.png",
```

观察组件只会在当前视角超过 `1.5×` 时加载对应高清图。加载成功后保持缩放、视角和
平移位置不变；加载失败则继续使用当前普通图。高清缓存最多保留两个视角。
