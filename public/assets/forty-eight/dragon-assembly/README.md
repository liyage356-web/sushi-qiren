# 二龙戏珠组装素材

当前视觉素材已按 1920×1080 组装画布接入。正式 PNG 均保留透明背景，
旧版 SVG 继续保留，仅作为图片加载失败时的明确名称占位回退。

- `background/courtyard-background.png`：后院水墨背景。
- `structure/yoke.png`：棕色弧形扁担。
- `structure/bucket-left.png`、`bucket-right.png`：左右古董糖药桶。
- `parts/dragon-left.png`：朝右的金色龙首，放在左端。
- `parts/dragon-right.png`：朝左的金色龙首，放在右端。
- `parts/gold-bead.png`：双龙之间的金色圆珠。
- `parts/pompom-left.png`、`pompom-right.png`：红色毛绒挂饰球。
- `parts/lacquer-sign.png`：金色书法“四十八样”。
- `parts/chain-left.png`、`chain-right.png`：两组青铜链条。
- `ui/step-seal.png`：巧夺天工朱印。
- `ui/panel-divider.png`：由链环素材裁切出的侧栏纹样。
- `audio/`：正式音效缺失，未使用无关声音代替。
- `manifest.json`：正式素材、SVG 回退与音效状态清单。

后续新增或替换素材时，保持清单中的文件名和透明背景不变即可。
